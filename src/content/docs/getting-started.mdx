## What exists now

The public site is a static Astro build deployed as Cloudflare Workers static assets. There is no origin server for HTML.

## What comes next

`app.dynasai.ai` will host:

1. Demo environment
2. Customer login
3. API keys and usage

Until that Worker is live, use [contact](/contact) for access.

## Local development

```bash
npm install
cp .env.example .env
npm run dev
```

Build and deploy:

```bash
npm run build
npx wrangler deploy
```
